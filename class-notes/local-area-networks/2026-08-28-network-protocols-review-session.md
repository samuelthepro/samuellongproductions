## Summary (Granola AI notes)

### Chapter 1 Review: Internet Architecture

-   Internet = pools of interconnected components:
    -   Network edge: hosts/end systems
    -   Network core: routers, switches, data networks
    -   Access network: links edge to core
-   Access network types:
    -   Wired: cable-based, DSL
    -   Wireless: LAN, cellular/wide-area
    -   Enterprise and data center networks
-   Key access network properties to remember:
    -   Shared vs. dedicated
    -   Symmetric vs. asymmetric (most are asymmetric: download >> upload)

### Network Core: Functions, Switching, and Delay

-   Two core functions:
    -   Routing: global path selection (like Google Maps)
    -   Forwarding/switching: local, per-router output link selection
-   Packet-based transmission effects:
    -   Store-and-forward: router waits for full packet before transmitting
    -   Queuing delay: packets wait in buffer when router is busy
    -   Packet loss: occurs when buffer overflows
-   Circuit switching vs. packet switching:
    -   Circuit switching: dedicated link, reliable, but wastes idle capacity
    -   Packet switching: dynamic, supports more users, but prone to queuing and loss
    -   Simulation demo: at 10% active probability, 35 users handled fine; at 30%, buffer overflow and retransmission occur
-   Four components of packet delay (nodal delay):
    -   Processing delay: header check, error detection (usually negligible)
    -   Queuing delay: wait time in buffer (requires queuing theory)
    -   Transmission delay: L/R (packet length / link rate)
    -   Propagation delay: D/S (link distance / speed of light, ~3×10⁸ m/s)

### Delay Calculation Examples

-   Three-link network example (from textbook website):
    -   Link 1: 10 Mbps, 1 km → transmission delay 4×10⁻⁴ s, propagation 3.33×10⁻⁶ s
    -   Link 2: 1 Mbps, 500 km → transmission 4×10⁻³ s, propagation 1.67×10⁻³ s; total ~5.67×10⁻³ s
    -   Link 3: 100 Mbps, 3 km → combined ~5×10⁻⁵ s
    -   Total end-to-end delay dominated by Link 2 (~10⁻³ scale)
-   Tollbooth car analogy (textbook example):
    -   10 cars = 1 packet; each car = 1 bit; toll service rate = 1/12 cars/sec
    -   Transmission delay: 10 cars × 12 sec = 120 sec (2 min)
    -   Propagation delay: 100 km ÷ 100 km/h = 60 min
    -   Total delay: 62 minutes
    -   Variant with faster propagation speed: to be worked through next Monday
