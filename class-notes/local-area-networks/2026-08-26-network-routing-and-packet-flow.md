## Summary (Granola AI notes)

### Network Core: Forwarding and Routing

-   Packets: application messages chunked into fixed-size L-bit pieces, transmitted one by one
-   Two core operations at every router:
    -   Forwarding (switching): local action, maps packet header to output port using a local forwarding table
    -   Routing: global action, algorithm computes best end-to-end path and populates each router’s forwarding table
-   Store-and-forward: router waits for entire packet to arrive before transmitting it onward
-   Queuing and packet loss:
    -   Occurs when input rate exceeds output rate (example: 100 Mbps in, 1.5 Mbps out)
    -   Packets buffer until buffer capacity exceeded, then dropped
    -   Recovery requires source to resend the lost packet

### Packet vs. Circuit Switching

-   Circuit switching: dedicated fixed link reserved for entire session
    -   Pros: guaranteed performance, no congestion
    -   Cons: idle time wastes resources; requires call setup
    -   Implemented via FDM (4 kHz channels per call) or TDM (125 µs slots)
    -   Example: 1 Gbps link, 100 Mbps per user = max 10 simultaneous users
-   Packet switching: each packet routed independently, links shared
    -   No call setup; routes can change packet-to-packet
    -   Subject to queuing delay and packet loss (buffer overflow)
    -   Example: 35 users, 10% active probability
        -   P(more than 10 active simultaneously) ≈ 0.004 (0.04%)
        -   Effectively supports ~3x more users than circuit switching
    -   Protocols for reliable transfer (congestion control) covered later

### Internet Structure and Packet Delays

-   Internet structure: hierarchical “network of networks”
    -   Direct mesh of all ISPs impractical: O(N²) links required
    -   Tier-1 (global) ISPs at the center, interconnected via Internet Exchange Points (IXPs) or peering links
    -   Regional ISPs sit below Tier-1; content providers (Google, Microsoft, Facebook) overlay on top
    -   Content providers connect directly to local ISPs, bypassing Tier-1 and regional ISPs
-   Four sources of nodal delay (total = sum of all four):
    -   Processing delay: header check, error detection, output port lookup (typically ~0)
    -   Queuing delay: wait time in buffer before transmission
    -   Transmission delay: time to push packet into link = L / R
    -   Propagation delay: time for one bit to travel the link = d / s (≈ 2–3 × 10⁸ m/s)
-   IV injection analogy maps all four delays:
    -   Nurse verifying prescription = processing delay
    -   Nurse serving other patients = queuing delay
    -   Pushing medicine into catheter = transmission delay
    -   Medicine traveling to patient’s vein = propagation delay
