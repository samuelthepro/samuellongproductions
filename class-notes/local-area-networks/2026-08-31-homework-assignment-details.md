### Protocol Layers

-   OSI 7-layer model: Physical, Data Link, Network, Transport, Session, Presentation, Application
    -   Mnemonic: “Please Do Not Throw Sausage Pizza Away”
-   TCP/IP collapses OSI into 5 layers; course follows TCP/IP with slight variation
    -   Application (covers OSI 5-7), Transport, Network (Internet), Data Link, Physical
-   Key device-to-layer mappings to memorize:
    -   Router = Layer 3, Switch = Layer 2, Multi-layer switch = Layer 3
-   Encapsulation flow: Message → Segment (+ transport header) → Datagram (+ network header) → Frame (+ link header)
    -   Each layer wraps the layer above’s output and passes it down
