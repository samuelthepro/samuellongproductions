### Python Review: Key Concepts Covered

-   Print function: passes any object convertible to a string; single or double quotes both valid, just can’t mix
-   Variables: Python is weakly typed, no need to declare type; reassignment allowed freely
    -   Simple types (int, float, string, bool) copy by value; complex types (lists, objects) copy by reference
    -   Reference behavior means changes through one variable reflect in all variables pointing to the same data
-   Assignment uses single `=`; equality testing uses `==`; multiple assignment supported (`x, y, z = 0, 1, 2`)
-   Arithmetic operators: `+`, `-`, `*`, `/` (float division), `//` (integer division, truncates decimal), `**` (exponentiation), `%` (modulus/remainder)
    -   Operator precedence mirrors standard math; use parentheses liberally to enforce intended order
-   Type conversion: mixed int/float expressions promote to float; explicit conversion via `int()`, `float()`, `str()`, `bool()`
-   Comments: strongly encouraged for partial credit and code reuse; explain purpose, not mechanics
