## Summary (Granola AI notes)

### Python Data Types and None

-   Automatic type conversion works for numbers; mixing types (e.g. string + int) throws an obvious error
-   `None` is a distinct type: not `0`, not `""`, not `False`
    -   Python requires a value at declaration; `None` is the workaround for uninitialized variables
    -   Most operations on `None` throw an error immediately, no silent failures

### Lists: Structure and Access

-   Lists: ordered, allow duplicates, defined with square brackets
    -   Tuples: same but immutable, use parentheses
    -   Sets: unordered, no duplicates, no index access
-   Zero-indexed: first element is index `0`
    -   Off-by-one errors are common, especially when switching from 1-indexed languages (e.g. MATLAB)
-   `len()` returns element count; works on lists, strings, tuples, and sets
-   `in` keyword checks membership, returns boolean; can negate with `not in`

### List Modification: append, insert, pop

-   `append(value)`: adds to end, no index needed, highly efficient
-   `insert(index, value)`: adds at specific position, slower
    -   Prefer `append` wherever possible; efficiency difference matters at scale
-   `pop()`: removes and returns last element by default (efficient)
    -   `pop(index)`: removes at specific index, slower
    -   Use `pop()` without index as the default pattern

### Control Flow: Conditionals and Loops

-   `if` / `elif` / `else` chains: only the first true condition executes, rest are skipped
    -   Python has no `switch` statement; use `if/elif/else` chains instead
    -   Logic errors (wrong relational operator, misaligned `else`) are harder to catch than syntax errors
    -   Avoid nesting beyond 2-3 levels; usually signals a cleaner solution exists
-   String comparison goes character by character using ASCII values; case-sensitive
-   `for` loops: count-controlled, always terminate
    -   `range(end)`, `range(start, end)`, `range(start, end, step)`; end value is exclusive
    -   Common pattern: `for i in range(len(data_structure))`
    -   `break` exits loop; `continue` skips current iteration
-   `while` loops: condition-controlled, use when collection size is unknown
    -   Prefer `for` when possible; `while` risks infinite loops
    -   IDE has ~10-second infinite loop timeout with auto-restart

### Functions and Classes

-   Functions: `def` keyword, no return type declaration needed
    -   Value-returning if it has a `return` statement; void if not
    -   Declare before calling; descriptive names strongly preferred
-   Classes: blueprints for data structures, persist data across calls (unlike functions)
    -   Named in UpperCamelCase by convention
    -   Every method requires `self` as first parameter; Python uses it to distinguish instances
    -   Constructor is `__init__`; sets up instance variables prefixed with `self.`
    -   Call methods via dot operator: `instance.method(args)`; `self` is passed implicitly
