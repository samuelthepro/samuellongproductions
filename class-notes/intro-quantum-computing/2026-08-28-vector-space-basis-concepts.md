### Vector Spaces and Subspaces Review

-   Recap of vector space properties: closure under addition and scalar multiplication
-   Subspace X defined as all linear combinations of two vectors V1 and V2 in space B
-   Proved X is a valid subspace by verifying both closure conditions:
    -   Closure under addition: W1 + W2 shown to be a linear combination of V1, V2, so stays in X
    -   Closure under scalar multiplication: λW1 shown to remain a linear combination of V1, V2

### Concrete Example in R³

-   V1 = (1,0,0), V2 = (0,1,0) in three-dimensional space
-   X defined as all combinations αV1 + βV2 for real α, β
-   Simplifies to vectors of the form (α, β, 0): the XY plane at Z = 0
-   V1 and V2 span the XY plane: any vector in that plane is a combination of these two

### Redundant Vectors and Spanning

-   Added V3 = (1,2,0) and defined set Y using V1, V2, V3
-   Key observation: V3 = V1 + 2·V2, so it is a linear combination of V1 and V2
-   V3 adds no new dimension; it stays within the XY plane
-   Proved Y = X: the third vector contributed nothing new to the span

### Definition of a Basis

-   Basis: the minimum set of vectors that span a given space
-   Vectors in a basis must not be linear combinations of each other (linearly independent)
-   V1, V2 form a valid basis for the XY plane (R²)
-   V1, V2, V3 together are not a basis: V3 is redundant
-   Test for basis: check that no vector in the set is a linear combination of the others
