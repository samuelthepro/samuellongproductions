## Summary (Granola AI notes)

### Vector Spaces: Definition

-   A vector space is a set of vectors with two closure rules:
    -   Closure under addition: adding any two vectors in the set yields a vector still in the set
    -   Closure under scalar multiplication: multiplying any vector by a real number yields a vector still in the set

### Subspaces: Definition and Requirements

-   A subspace X is a subset of a vector space V satisfying both closure conditions
-   Two requirements (both must hold; one failure is sufficient to disqualify):
    1.  Closure under addition: V1, V2 ∈ X → V1 + V2 ∈ X
    2.  Closure under scalar multiplication: V1 ∈ X, λ ∈ ℝ → λV1 ∈ X
-   Standard space Rⁿ can be 1D (real line), 2D (XY plane), 3D (XYZ), or any N dimensions

### Example 1: Z = 1 Plane in R³ (Not a Subspace)

-   X defined as all vectors (x, y, 1) in R³
    -   Geometrically: the XY plane shifted up by 1
-   Closure under addition fails:
    -   V1 = (2, 1, 1) and V2 = (3, 1, 1) both ∈ X
    -   V1 + V2 = (5, 2, 2): z = 2, not 1, so not in X
-   Conclusion: X is not a subspace of R³

### Example 2: Z = 0 Plane in R³ (Is a Subspace)

-   X defined as all vectors (x, y, 0) in R³
-   Closure under addition holds:
    -   (x1, y1, 0) + (x2, y2, 0) = (x1+x2, y1+y2, 0): z stays 0
-   Closure under scalar multiplication holds:
    -   λ(x1, y1, 0) = (λx1, λy1, 0): z stays 0
-   Conclusion: X is a subspace of R³
-   Key insight: shifting the plane to z = 0 (through the origin) is what makes it a subspace

### Examples 3 & 4: x + y = 1 vs. x + y = 0 in R²

-   x + y = 1: not a subspace
    -   V1 = (1, 0), V2 = (0, 1) both satisfy x + y = 1
    -   V1 + V2 = (1, 1): x + y = 2 ≠ 1, fails closure under addition
    -   Scalar check also fails: 3 × (1, 0) = (3, 0), x + y = 3 ≠ 1
-   x + y = 0: is a subspace
    -   General proof: (x1 + x2) + (y1 + y2) = (x1 + y1) + (x2 + y2) = 0 + 0 = 0
    -   Scalar check: λ(x1 + y1) = λ × 0 = 0
    -   Both conditions satisfied for all general values
