## Summary (Granola AI notes)

### Inner Product and Vector Length

-   Inner product (dot product) of two vectors V1, V2 in R^N: sum of element-wise products
    -   V1·V2 = x₁₁x₂₁ + x₁₂x₂₂ + … + x₁ₙx₂ₙ
    -   Example: V1=(1,2,3), V2=(4,5,6) → 4+10+18 = 32
-   Length (norm) of a vector: ||V1|| = √(V1·V1)
    -   Example: ||V1=(1,2,3)|| = √14, ||V2=(4,5,6)|| = √77
-   Angle between two vectors via dot product:
    -   cos θ = (V1·V2) / (||V1|| × ||V2||)

### Orthogonality Defined

-   Two vectors are orthogonal if the angle between them is 90°
    -   cos(90°) = 0, so V1·V2 = 0
-   Key rule: V1 and V2 are orthogonal if and only if V1·V2 = 0

### Orthogonal vs. Non-Orthogonal Bases

-   Multiple valid basis sets exist for any space (e.g., R²)
-   Orthogonal basis example: V1=(1,0), V2=(0,1)
    -   V1·V2 = 0, confirmed orthogonal
-   Non-orthogonal basis example: V3=(1,1), V4=(2,−7)
    -   Both are independent, valid basis for R², but V3·V4 ≠ 0

### Advantage of Orthogonal Bases: Solving for Coefficients

-   Any vector can be expressed as α·B1 + β·B2 for a given basis
-   Non-orthogonal case (V3, V4): must solve a system of two simultaneous equations for α and β
-   Orthogonal case: take the dot product of both sides with each basis vector
    -   V5·V6 = 0 eliminates the other term, leaving one equation per coefficient
    -   α = (V·V5) / (V5·V5), β = (V·V6) / (V6·V6)
-   Example with V5=(1/√2, 1/√2), V6=(1/√2, −1/√2) and target vector (7,11):
    -   α = 18/√2, β = −4

### Orthonormal Bases

-   Orthonormal = orthogonal + each vector normalized to unit length (||V||=1)
    -   Inner product of a vector with itself equals 1
    -   Simplifies coefficient formula: denominator = 1, so α = V·V5 directly
-   V5 and V6 above are orthonormal: V5·V5 = ½ + ½ = 1
